# 带符号标记排列 · 规范倒位审计页

基因组装配复核场景的纯浏览器工具：输入 3 至 7 个带符号标记组成的排列
（绝对值必须恰好为 1 至 n 且互异）。支持两种审计模式，均在浏览器内**精确枚举**：

- **普通模式**：枚举全部**最少倒位步数**方案；
- **风险审计模式**：为 n+1 个切口各填写 1 至 9 的正整数风险，区间 `[i,j]`
  的代价取两端切口风险（切口 i 与切口 j+1）之和，枚举全部**最低累计风险**
  方案。污染与重复测序风险随切口变化时，倒位次数最少不再代表实验代价最低——
  同优方案的步数可以不同。

两种模式都精确给出：

- 最低代价（普通模式为最少倒位步数，风险模式为最低累计风险）；
- 全部最优方案总数（bigint 任意精度，十进制展示）；
- **规范方案**：在全部最优方案中，按每步倒位 `(起, 止)` 下标对序列的字典序
  选出的唯一方案（不同长度的同优方案按字典序前缀规则比较），可逐步 / 拖动滑块
  查看每一步的状态；风险模式下还标注每步代价；
- **深度 × 区间矩阵**：每格表示“在该深度选择该区间”的最优方案数量，并标注
  - 绿：**该深度仍存活的全部**方案都出现；
  - 黄：**部分**仍存活方案出现；
  - 灰：**任何**仍含该深度的方案中均未出现；

  矩阵按实际步骤深度展示，**行数覆盖最长同优轨迹**；每行的比较全集是
  “仍包含该深度（长度大于该深度）”的方案，普通模式下每行都等于方案总数，
  风险模式下较短方案在其收尾后退出全集（表格末列给出每行全集数），
  长方案逐深度继续计数——不截断、不重复计数。

  点击任意格，规范轨迹联动跳转到对应深度并高亮该步区间（规范选择始终白色描边；
  点击超出规范轨迹步数的行时，轨迹停在规范终点、该格仍高亮并显示精确计数）。
- 非法输入（排列或风险）一次性合并给出全部错误，两份输入文本始终保留。

**全部切口等权时**（风险均为 r，每条路径风险 = 2r × 步数），风险模式的
最低风险方案数、规范轨迹和各有效深度的矩阵归属与普通模式的最少步数审计**逐项一致**。

**无业务后端、无持久化、无任何在线调用。** 容器只运行一个极简静态文件服务器
（`server/server.mjs`，约 100 行），计算全部在浏览器（Web Worker）内完成。

## 倒位语义与切口语义

选择闭区间 `[i, j]`（1 基），将区间内标记次序反转，并同时翻转每个符号。
例：`[1,-3,-2,4]` 在 `[2,3]` 上倒位 → `[1,2,3,4]`，故最短步数为 **1**。

n 个标记有 n+1 个切口：切口 k 位于标记 k 之前（1 基），末切口位于标记 n 之后。
区间 `[i,j]` 的两端切口是 i 与 j+1，风险代价 = `risk[i] + risk[j+1]`（2 至 18）。

风险改变最优解的例子：`[1,-3,-2,4]` 直接修复只需倒位 `[2,3]`，但在切口风险
`1 1 1 6 1` 下其代价为 7；而 3 步绕行 `[2,4] → [3,4] → [2,4]` 每步代价 2，
累计 6，成为唯一最低风险方案——更长的轨迹反而实验代价更低。

## 本地开发（Node 20+）

```bash
npm ci
npm test          # vitest：含 n=3 全部排列 × 多组风险的暴力枚举交叉验证
npm run build     # tsc --noEmit + vite 静态构建到 dist/
npm run dev       # 本地热更新开发
PORT=8080 npm run serve:static   # 用静态服务器发布已构建的 dist/
npm run smoke     # 对运行中的服务做 HTTP 冒烟（BASE_URL 可覆盖）
```

   × 多组风险的独立暴力枚举，交叉验证最优代价 / 总数 / 规范字典序 /
   逐深度格计数与比较全集，以及等权时与普通模式逐项一致）；
2. 构建检查（TypeScript 类型检查 + Vite 生产构建）；
3. 需求核查：`[1,-3,-2,4]` 最短步数为 1（唯一倒位 `[2,3]`）、
   重复绝对值被拒绝、风险非法输入合并反馈、高风险切口使更长轨迹成为
   最低风险方案；
4. HTTP 冒烟：等待页面可访问后检查 `/healthz`、首页 HTML 与构建资源。

## 算法说明

状态空间至多 `2^n · n!`（n=7 时 645,120 个状态），每状态至多 `n(n+1)/2 = 28`
个倒位。状态压进一个整数（每个带符号标记 4 位），倒位用位运算枚举。

**普通模式（单位权）：**

1. 前向 BFS（初始态出发）得到最短距离；邻居按 `(i,j)` 字典序枚举，首次到达
   各状态的父边即构成字典序最小的最短方案；
2. 反向 BFS（目标态出发，只保留位于某条最短路径上的状态），分层 DP 计算每个
   状态到目标的最短路径数（bigint）；
3. 从初始态逐层枚举“最短边”，按区间聚合格计数
   （边计数 = 前缀方案数 × 后缀方案数），得到深度×区间矩阵。

**风险模式（正整数小权值 2..18）：**

1. 倒位自逆且区间代价关于方向对称，状态图无向：从目标跑一次 Dial 桶式
   Dijkstra（边权为 2..18 的小整数，无需堆）即得各状态到目标的最低风险
   `dist`，初始态距离即最优代价；边 `(u,v)`（权 w）属于某条最优路径
   当且仅当 `dist(v) = dist(u) - w`；
2. 后缀方案数 `ways[u]` 在最优子图上按 `distF` 递减做 bigint DP；
3. **按精确深度分层**的前缀 DP：`prefix[d](u)` 是恰在第 d 步到达 u 的最优
   方案数（同一状态可在不同深度以相同累计代价出现，不做跨深度合并）；
   边 u→v 在深度 d 的计数 = `prefix[d](u) × ways[v]`。步长较长的同优方案
   逐层继续贡献、在收尾后自然退出全集，因此既不截断也不重复计数；
4. 规范轨迹从初始态贪心选择“仍可沿最优边收尾”的字典序最小边——不同长度的
   序列按字典序前缀规则比较，结论与枚举全部最优序列一致。

全部切口等权时风险模式直接复用普通模式的 BFS 结果，不另走加权路径。

因此结果不是贪心近似——枚举的是**全部**最优方案；风险模式下同优方案步数
不同也能完整暴露等代价替代路径。
