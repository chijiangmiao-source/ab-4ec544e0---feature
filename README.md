# 带符号标记排列 · 规范倒位审计页

基因组装配复核场景的纯浏览器工具：输入 3 至 7 个带符号标记组成的排列
（绝对值必须恰好为 1 至 n 且互异），在浏览器内**精确枚举全部最优倒位方案**。
两种审计模式：

- **普通模式**：每条倒位代价 1，最优 = 倒位次数最少；
- **风险审计模式**：为 n+1 个切口各填一个 1 至 9 的正整数风险
  （r₀ 在标记 1 左侧、r_k 在标记 k 与 k+1 之间、r_n 在标记 n 右侧），
  倒位 [i,j] 的代价 = r_{i-1} + r_j，最优 = **累计风险最低**。
  代价不再等同时，最少倒位次数不再代表实验代价最低，同优方案的步数也可不同。

两种模式均给出：

- 最优累计代价（普通模式为最少倒位步数，风险模式为最低累计风险）；
- **最优方案总数**（bigint 任意精度，十进制展示），同优方案即使步数不同
  也不会被截断或重复计数；
- **规范方案**：在全部最优方案中，按每步倒位 `(起, 止)` 下标对序列的字典序
  选出的唯一方案（短序列仅在为真前缀时更小），可逐步 / 拖动滑块查看；
- **深度 × 区间矩阵**：矩阵按实际步骤深度展示，行数覆盖**最长的同优轨迹**；
  每行以**仍包含该深度**的方案为比较全集（行首标注该全集数量），每格表示
  “在该深度选择该区间”的最优方案数量，并标注
  - 绿：**该行全部**方案都出现；
  - 黄：**部分**方案出现；
  - 灰：该深度**任何**方案中均未出现；

  点击任意格，规范轨迹联动跳转到对应深度并高亮该步区间（规范选择始终白色描边）。
- 排列与风险输入均为非法时一次性合并给出全部错误，输入文本始终保留。
- **全部切口等权（均为 1）时**：最优方案数、规范轨迹、各有效深度的矩阵归属
  与普通模式的最少步数审计完全一致（每条倒位代价为 2，最低累计风险 = 2 × 步数）。

**无业务后端、无持久化、无任何在线调用。** 容器只运行一个极简静态文件服务器
（`server/server.mjs`，约 100 行），计算全部在浏览器（Web Worker）内完成。

## 倒位语义

选择闭区间 `[i, j]`（1 基），将区间内标记次序反转，并同时翻转每个符号。
例：`[1,-3,-2,4]` 在 `[2,3]` 上倒位 → `[1,2,3,4]`，故最短步数为 **1**。

## 本地开发（Node 20+）

```bash
npm ci
npm test          # vitest：含对 n=3 全部 48 个排列的暴力枚举交叉验证
npm run build     # tsc --noEmit + vite 静态构建到 dist/
npm run dev       # 本地热更新开发
PORT=8080 npm run serve:static   # 用静态服务器发布已构建的 dist/
npm run smoke     # 对运行中的服务做 HTTP 冒烟（BASE_URL 可覆盖）
```

## 一次性验证服务 verify

```bash
docker compose run --build verify
```

`verify` 服务会在 `web` 健康检查通过后自动执行，并以**容器退出码**报告结果
（`docker compose ps -a verify` 可查看 `Exited (0)`）：

1. 单元测试（vitest：含独立暴力枚举交叉验证普通模式的距离 / 总数 / 规范字典序，
   以及风险模式在 n=3 全部排列 × 多组风险向量与 n=4 抽样上的最低风险 /
   任意精度总数 / 变长步数 / 逐深度格计数 / 规范字典序）；
2. 构建检查（TypeScript 类型检查 + Vite 生产构建）；
3. 需求核查：`[1,-3,-2,4]` 最短步数为 1（唯一倒位 `[2,3]`）、
   重复绝对值被拒绝、风险输入非法被合并拒绝、等权与普通模式一致、
   非等权时给出最低累计风险且变长同优方案矩阵行数/行全集正确；
4. HTTP 冒烟：等待页面可访问后检查 `/healthz`、首页 HTML 与构建资源。

## 算法说明

状态空间至多 `2^n · n!`（n=7 时 645,120 个状态），每状态至多 `n(n+1)/2 = 28`
个倒位。状态压进一个整数（每个带符号标记 4 位），倒位用位运算枚举：

1. 前向 Dijkstra（普通模式边权恒 1，即 BFS；风险模式边权 2..18，桶式优先队列）
   得到初始态到各态的最低累计代价 `distF`；普通模式邻居按 `(i,j)` 字典序枚举，
   首次到达各状态的父边即字典序最小的最优方案；
2. 从目标态反向收集**最优 DAG**（边 (u,v) 满足 `distF[u]+w=distF[v]`），
   在其上计算每个状态到目标的最优路径条数（bigint）、最少/最多步数，
   以及风险模式下按步骤序列字典序选出的规范父边；
3. 从初始态按**步骤深度**逐层枚举最优边，按区间聚合格计数
   （边计数 = 以恰好该深度到达起点的前缀数 × 后缀方案数），得到深度×区间矩阵；
   每层只统计仍包含该深度的方案（已到达目标的方案不再计入后续深度）。

风险模式下最优路径长度可不同（便宜倒位多走、贵倒位少走），故矩阵按深度而非
代价层组织：第 d 行的比较全集是“至少还有 d+1 步要走”的方案，其和等于该全集，
不强制等于总方案数。普通模式下所有最优路径等长，每行全集恰为总方案数。

因此结果不是贪心近似——“眼前减少断点最多”的局部贪心可能错过全局最优修复、
也无法暴露等代价替代路径；这里枚举的是全部最优方案。
